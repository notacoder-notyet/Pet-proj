# Проект: Классификация для прогностического обслуживания (Predictive Maintenance)

## Цель
Построить модель машинного обучения для предсказания отказов оборудования (бинарная классификация) на основе данных с датчиков.

## Технологический стек
- Python 3.9+
- pandas, numpy (обработка данных)
- matplotlib, seaborn (визуализация)
- scikit-learn (базовые модели)
- xgboost (основная модель)

## Правила для ИИ (AI Rules)
1. Всегда предлагай краткий план действий перед написанием кода.
2. Пиши чистый, читаемый код. Комментарии в коде должны быть на русском и английском языке вместе.
3. Используй Jupyter Notebook для разведочного анализа (EDA) и построения моделей.
4. Сравни как минимум 3 модели: Logistic Regression, Random Forest и XGBoost.
5. Используй метрику F1-score в качестве основной для оценки качества.
6. Обязательно строй матрицу ошибок (confusion matrix) для лучшей модели.
7. Обосновывай свои решения (почему выбрана эта модель, зачем нужна конкретная предобработка данных).
8. Учитывай что для моделей будет использоваться GPU AMD Vega 56.
